# Назва проєкту
UniSells

# Проблема, яку вирішуємо
Початківцям (Junior) надзвичайно складно отримати перші замовлення на класичних фріланс-біржах через високу конкуренцію з досвідченими спеціалістами. З іншого боку, досвідчені розробники (Middle/Senior) витрачають багато часу на фільтрацію стрічки від простих і низькооплачуваних завдань. Відсутність автоматичного сортування замовлень за рівнем кваліфікації створює хаос на ринку, демотивує новачків та знижує ефективність роботи професіоналів.

# Цільова аудиторія
* **Основна аудиторія:** Програмісти-початківці (Junior/Trainee), які шукають перші реальні проєкти для наповнення портфоліо та старту кар'єри без стресу.
* **Вторинна аудиторія:** Досвідчені розробники, які шукають високооплачувані та складні завдання; замовники (бізнес/стартапи), яким потрібно підібрати виконавця з чітко підтвердженим рівнем навичок під їхній бюджет.
* **Ключові характеристики:** Користувачі прагнуть прозорості у виборі завдань (наприклад, чіткий поділ на таски для React або C#) та зацікавлені в поступовому підвищенні свого професійного рейтингу.

# Опис продукту
Продукт буде реалізований як веб-застосунок (фріланс-платформа для ІТ-фахівців). Головна архітектурна особливість — система грейдування (Skill-gating). Під час реєстрації та роботи розробник отримує певний рівень (наприклад, Newbie, Pro, Expert). Слабкі розробники бачать і можуть брати лише відповідні їм завдання, а сильні програмісти отримують ексклюзивний доступ до дорогих і складних проєктів.

# Основна функціональність
* Реєстрація з вибором ролі (Замовник / Розробник) та заповненням стека технологій.
* Базова система верифікації навичок для призначення початкового рівня розробнику.
* Розумна стрічка замовлень: автоматична фільтрація завдань відповідно до рівня (грейду) виконавця.
* Створення замовлень із вказівкою складності, бюджету та необхідних технологій.
* Вбудована система безпечної здачі проєкту та обміну повідомленнями.
* Гейміфікація: система прогресії, яка дозволяє розробнику підвищувати свій рівень на платформі за успішно виконані завдання.
