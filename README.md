# UniSells

**UniSells** — це двостороння фріланс-платформа (IT-маркетплейс) формату P2P/C2C, розроблена спеціально для вирішення проблеми старту кар'єри Junior-спеціалістів та зручного пошуку перевірених виконавців для замовників.

Головна особливість платформи — інноваційна система **Skill-Gating** та розумного балансування (MMR), яка автоматично фільтрує замовлення відповідно до реального підтвердженого рівня розробника.

## Ключові можливості
* **Smart Feed (Розумна стрічка):** Автоматичне відсікання завдань, які не відповідають рангу виконавця.
* **Динамічний MMR:** Чесна система нарахування рейтингу на основі оцінок замовника та складності ТЗ (визначається алгоритмами бота).
* **Real-Time комунікація:** Вбудований чат та система миттєвих сповіщень.

## Технологічний стек
* **Frontend:** React (TypeScript), Vite, Bootstrap 5, Zustand, React Query.
* **Backend:** .NET 8 (C#), ASP.NET Core Web API, Clean Architecture, SignalR.
* **Бази даних & Storage:** PostgreSQL (основна СУБД), Redis (In-Memory кеш), MinIO / AWS S3 (файлове сховище).
