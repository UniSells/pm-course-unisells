# Стек технологій та архітектура платформи UniSells

## Огляд продукту та Бізнес-модель
* **Тип платформи:** Двосторонній IT-маркетплейс (Two-Sided Marketplace).
* **Бізнес-модель (Поточний етап):** P2P / C2C (Peer-to-Peer / Consumer-to-Consumer). Платформа фокусується на прямій взаємодії приватних замовників та фрілансерів, вирішуючи проблему старту кар'єри для Junior-фахівців.
* **Формат продукту:** Responsive Web Application (Веб-додаток). Адаптивна верстка, підтримка кросбраузерності, мобільних та десктопних пристроїв без створення окремих нативних додатків.

---

## 1. Основний технологічний стек (Core Stack)

### Backend
* **Платформа / Фреймворк:** .NET 8 / ASP.NET Core Web API (C#)
* **Архітектурний підхід:** Clean Architecture (Domain, Application, Infrastructure, API)
* **ORM:** Entity Framework Core (PostgreSQL Provider)
* **Безпека та авторизація:** JWT (Access/Refresh Tokens), ASP.NET Core Policy-Based Authorization для обмеження доступу до ендпоінтів за рангами та правами.

### Frontend
* **Фреймворк / Бібліотека:** React (TypeScript)
* **Збирач:** Vite
* **UI & Стилізація:** Bootstrap 5 (React-Bootstrap / Bootstrap React) — адаптивні сітки, компоненти модальних вікон, картки замовлень, Toasts та Badges.
* **Управління станом (Client State):** Zustand — глобальне сховище даних авторизації, профілю та інтерфейсних налаштувань.
* **Запити та Кешування (Server State):** React Query (TanStack Query) + Axios — обробка асинхронних запитів до API, кешування та оновлення даних у фоновому режимі.

---

## 2. Архітектура збереження даних (Storage Architecture)
* **Основна СУБД (PostgreSQL):** Збереження цінних структурованих даних (користувачі, ранги, MMR, замовлення, відгуки, відгуки-оцінки, історія чатів).
* **In-Memory СУБД (Redis):** Збереження тимчасових швидких даних (кеш стрічки замовлень, токен-блеклисти, онлайн-статуси користувачів, Rate Limiting).
* **Сховище файлів (MinIO / AWS S3):** Ізольоване збереження медіа та важких документів (аватарки, файли ТЗ, архіви виконаних робіт).

---

## 3. Система комунікацій та Real-Time (SignalR)
* **Протокол та Фреймворк:** ASP.NET Core SignalR (WebSockets з фолбеком на Server-Sent Events / Long Polling).
* **Вбудований чат:** Миттєвий обмін повідомленнями між замовником та виконавцем за конкретним замовленням.
* **Система сповіщень (In-App Notifications):**
  * Пуш-сповіщення в інтерфейсі про нові відгуки на замовлення (Bootstrap Toasts).
  * Зміна статусу замовлення (в роботі, на перевірці, завершено).
  * Оповіщення про підвищення рангу / зірки або отримання нового досягнення.
* **Онлайн-статуси:** Відстеження присутності користувачів у мережі в режимі реального часу.
