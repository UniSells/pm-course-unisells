# Стек технологий и архитектура платформы UniSells

## Обзор продукта и Бизнес-модель

* **Тип платформы:** Двусторонний IT-маркетплейс (Two-Sided Marketplace).
* **Бизнес-модель (Текущий этап):** **P2P / C2C (Peer-to-Peer / Consumer-to-Consumer)**. Платформа фокусируется на прямом взаимодействии частных заказчиков и фрилансеров, решая проблему старта карьеры для Junior-специалистов.
* **Формат продукта:** Responsive Web Application (Веб-приложение). Адаптивная верстка, поддержка кроссбраузерности, мобильных и десктопных устройств без создания отдельных нативных приложений.

---

## 1. Основной технологический стек (Core Stack)

### Backend
* **Платформа / Фреймворк:** .NET 8 / ASP.NET Core Web API (C#)
* **Архитектурный подход:** Clean Architecture (Domain, Application, Infrastructure, API)
* **ORM:** Entity Framework Core (PostgreSQL Provider)
* **Безопасность и авторизация:** JWT (Access/Refresh Tokens), ASP.NET Core Policy-Based Authorization для ограничения доступа к эндпоинтам по рангам и правам.

### Frontend
* **Фреймворк / Библиотека:** React (TypeScript)
* **Сборщик:** Vite
* **UI & Стилизация:** Bootstrap 5 (React-Bootstrap / Bootstrap React) — адаптивные сетки, компоненты модальных окон, карточки заказов, Toasts и Badges.
* **Управление состоянием (Client State):** Zustand — глобальное хранилище данных авторизации, профиля и интерфейсных настроек.
* **Запросы и Кэширование (Server State):** React Query (TanStack Query) + Axios — обработка асинхронных запросов к API, кэширование и обновление данных в фоновом режиме.

---

## 2. Архитектура хранения данных (Storage Architecture)

* **Основная СУБД (PostgreSQL):** Хранение ценных структурированных данных (пользователи, ранги, MMR, заказы, отклики, отзывы, история чатов).
* **In-Memory СУБД (Redis):** Хранение временных быстрых данных (кэш ленты заказов, токен-блеклисты, онлайн-статусы пользователей, Rate Limiting).
* **Хранилище файлов (MinIO / AWS S3):** Изолированное хранение медиа и тяжелых документов (аватарки, файлы ТЗ, архивы выполненных работ).

---

## 3. Система коммуникаций и Real-Time (SignalR)

* **Протокол и Фреймворк:** ASP.NET Core SignalR (WebSockets с фоллбэком на Server-Sent Events / Long Polling).
* **Встроенный чат:** Мгновенный обмен сообщениями между заказчиком и исполнителем по конкретному заказу.
* **Система уведомлений (In-App Notifications):**
  * Пуш-уведомления в интерфейсе о новых откликах на заказ (Bootstrap Toasts).
  * Изменение статуса заказа (в работе, на проверке, завершен).
  * Оповещение о повышении ранга / звезды или получении нового достижения.
* **Онлайн-статусы:** Отслеживание присутствия пользователей в сети в реальном времени.
